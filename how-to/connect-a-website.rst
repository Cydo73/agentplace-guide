Connect a website and check what the Builder read
=================================================

**Last checked:** |last_checked| against Agentplace's public documentation.

Use this guide when you give the Builder a website address and want to know how much of the site it actually used.

Before you start
----------------

You need the address of the site and a few items you can find on it, such as a product, a price and a policy page.

Steps
-----

1. Send the Builder the address and the result you want, for example: "Create an agent using https://example.com. Help customers choose a product and request a quote."

2. Ask the Builder what it used. Send this:

   .. code-block:: text

      Which pages of the website did you read, and which products or
      listings did you find? Tell me what you could not read.

3. Pick five items from the live site. Include one from the homepage, one from a deeper page and one that loads after you scroll or click.

4. Ask the agent about each of the five in Preview. Note which ones it knows.

5. If any are missing, follow :doc:`Fix missing information <fix-missing-information>`.

6. Write down today's date. A website address connects the content once. It does not keep the agent in sync with later changes.

What to expect
--------------

Agentplace says the Builder starts with the homepage and a useful customer action, then expands the experience as you refine it. Do not assume every page has been recreated. If a page cannot be read or needs a login, give the Builder the files or text instead. A website address does not connect a booking system, customer database or payment account.
