Publish your agent and check the live link
==========================================

**Last checked:** |last_checked| against Agentplace's public documentation.

Use this guide when you are ready to let real visitors use the agent.

Steps
-----

1. Complete one realistic customer task in Preview.

2. Start the publish flow.

3. Choose who can use the agent:

   * Public: anyone with the link.
   * Restricted: specific email addresses or domains.
   * Private: you only, after signing in.

4. For a public agent, choose whether visitors must sign in, and whether others may duplicate the agent.

5. Complete the publish flow and copy the link it gives you.

6. Open the link in a private browser window. Ask two questions and open it on a phone.

7. Check anything that changed. Review the publishing summary for connections and scheduled work, because a Preview edit goes live when you publish it.

After publishing
----------------

* **To change something:** edit in the workspace, test in Preview, then publish again.
* **To go back:** open Versions, restore a saved snapshot, test it in Preview and publish when ready. Restore changes the working version, not the live one.
* **To make a separate copy:** use Duplicate. The copy is independent and needs its own publish.
* **To take it offline:** use Unpublish. Private is not the same, because a private agent stays published for you.

What restoring does not do
--------------------------

Restoring an old version does not cancel a booking, refund a payment or recall an email that was already sent. Handle those in the relevant system.
