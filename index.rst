Agentplace Beginner Guide
=========================

A tutorial, task guides, a test reference and a set of findings, written while I built and stress tested a travel agent on Agentplace.

.. note::

   This is an independent guide. It is not official documentation from Agentplace, and the Tubayo example is not an official Tubayo product. It was written on 2 November 2026. Agentplace changes its product, so check its own documentation for current behavior.

Start here
----------

* New to Agentplace? Follow the :doc:`tutorial <tutorial/index>`.
* Something went wrong with your agent? Try the :doc:`how to guides <how-to/index>`.
* Want the exact test questions and terms? See the :doc:`reference <reference/index>`.
* Want to know why agents miss information? Read the :doc:`explanations <explanation/index>`.
* Want the results of my tests? Go to the :doc:`findings <findings/index>`.
