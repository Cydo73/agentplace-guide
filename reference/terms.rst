Terms and facts
===============

Terms as Agentplace documents them. Agentplace documentation was last updated on 24 September 2026. Check the `current documentation <https://agentplace.io/docs>`__, because the product changes.

.. list-table::
   :header-rows: 1
   :widths: 25 75

   * - Term
     - What it means
   * - Builder
     - The AI in the Agentplace workspace that helps you discuss, create and refine an agent. It does not know your private business details until you give them.
   * - Preview
     - The working version of your agent that you test before releasing it. Also called the draft.
   * - Publish
     - Releases the agent at its own link, using the access settings you confirm.
   * - Publish again
     - Applies a new version or changed settings to the same published agent.
   * - Duplicate
     - Creates a separate draft from an existing agent. Changes do not sync between the two.
   * - Unpublish
     - Takes the published agent offline. The working draft stays in your workspace.
   * - Versions
     - Saved snapshots of your agent. You can restore one as the working version.
   * - Restore
     - Replaces the working version with a saved snapshot. It does not change the live agent and does not undo bookings, payments or emails.
   * - Public
     - Anyone with the link can use the agent.
   * - Restricted
     - Only specific email addresses or domains can use it.
   * - Private
     - Only you can use it, after signing in. The agent stays published.
   * - Require sign in
     - A setting for public agents. Visitors must sign in to use them.
   * - Allow duplication
     - A setting for public agents. Others can copy your agent through its Remix URL.
   * - Agent URL
     - The link customers use to open your published agent.
   * - Remix URL
     - A link that starts a separate copy of your agent in someone else's workspace, when duplication is allowed.
   * - GPT-6 Luna
     - A model that Agentplace says is always free in the Builder and in your agent, even with zero credits.
   * - AI credits
     - Usage allowance for models other than Luna. One credit is not one message. Different requests use different amounts.

Credit facts
------------

* When credits run out, your agent switches to GPT-6 Luna automatically.
* Free model use does not remove charges for connected services, scheduled work or other plan features.
* Opening the agent can start AI work, and that work uses credits on paid models. Luna stays free.
* For current plans and limits, use the `Pricing page <https://agentplace.io/pricing>`__ rather than copying a number from a guide.
